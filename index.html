先说清楚First, the basics

AI Agent 不是聊天机器人An AI agent is not a chatbot

聊天机器人回答「一般来说」；Agent 回答「你的业务现在是什么情况」，而且能动手去查、去办。A chatbot answers in generalities. An agent answers what is happening in your business right now, and it can go and look things up or get them done.

Agent 的上限，取决于它能接触到的系统和数据An agent is only as good as the systems and data it can reach

只有系统，没有 AISystems without AI
数据躺在库里。报表月底才出，异常要等人发现。Data sits in the database. Reports come at month end, and problems wait for someone to notice.
只有 AI，没有系统AI without systems
没有东西可看。模型只能给通用答案，和你的业务无关。There is nothing to look at. The model can only give generic answers that have nothing to do with your business.
两者一起Both together
系统负责留下痕迹，Agent 负责从痕迹里看出问题、把事办了。The system keeps the record; the agent reads it, spots the problems and gets things done.

可以把 Agent 当成一个会用你们系统的新员工：要给它权限、给它规矩，也要检查它的工作。Think of an agent as a new hire who can use your systems: it needs permissions and rules, and someone checking its work.

路径一 · 数据和流程还很乱Path 1 · Messy data and processes

先做系统，把数据理顺Build the system, put the data in order

沟通只靠工作群、Excel 来回传的时候，先由系统把信息接住：识别、校验、统一口径，存成有编号、有版本、有权限的记录。数据和流程规范之后，再接入 Agent。When work runs on group chats and spreadsheets passed around, the system catches the information first: extracted, checked, put on one definition and stored as records with an ID, a version and permissions. Once data and processes are standardized, the agent plugs in.

  • 可查Searchable每件事都有编号和时间every event has an ID and a time
  • 可比Comparable口径统一，各部门的数字对得上one definition, so every team's numbers agree
  • 可追溯Traceable谁、何时、改了什么，一清二楚who changed what, and when, is always clear
  • 可计算Computable补货、预警、报表可以自动跑reorders, alerts and reports can run themselves

路径二 · 痛点明确，直接接入Path 2 · A clear pain point, plugged in directly

接入 Agent，降本增效Plug in the agent: lower cost, faster work

痛点明确、数据可用的，比如制造业排产、公司文档检索，可以直接接入 Agent；走路径一的，系统就绪后同样接上来。Agent 先查系统和资料，按查到的内容回答，能动手出草稿、发预警，每一步都可以核对。Where the pain point is clear and the data is usable, such as production scheduling or searching company documents, the agent plugs in directly. On path 1 it connects once the system is ready. It checks systems and documents first, answers from what it finds, drafts and raises alerts, and every step can be checked.

  • 先查后答Looks first按查到的记录回答，查不到就说查不到answers from records, and says so when it finds nothing
  • 可核对Checkable调用了什么工具、引用了哪条记录，都看得到every tool call and cited record is visible
  • 按权限Role-based和员工一样分角色，看不到不该看的like staff, it only sees what its role allows

可靠性Trust

让 Agent 能放心用的六个设计Six choices that make an agent safe to use

都已在 CoachSpace 的 AI 助手里实现，可以原样用到其他业务。All six are built into the CoachSpace assistant and carry over to any business.

GROUNDED

只按查到的数据回答Answers only from what it looked up

工具没查到就直接说没查到，不编一个看起来对的答案。When the tools return nothing, it says so instead of inventing a plausible answer.

SCOPED

权限从结构上隔离Isolation is structural

每个工具只能读本俱乐部的数据，跨俱乐部查询在代码层面就写不出来。Every tool reads one club's data only, so a cross-club query can't even be expressed.

ROLE-BASED

敏感能力按角色给Sensitive tools follow the role

工资报表只给老板，员工的助手里根本没有这个工具，而不是查完再过滤。Pay reports go to owners only. A staff member's assistant never receives the tool, rather than filtering its output.

CAPPED

成本有上限Spending has a ceiling

每个俱乐部每天有调用额度；额度读不到时直接拒绝，杜绝失控的账单。Each club has a daily allowance. If the counter can't be read, requests are refused, so a runaway bill can't happen.

TRACEABLE

每个回答都可追溯Every answer is traceable

回答附带调用了哪些工具、引用了哪些记录，管理员可以逐条核对。Each answer lists the tools it ran and the records it cited, so an admin can check every one.

TESTED

每次改动都自动把关Checked on every change

109 条专门测试；每次提交代码都自动检查数据泄露，漏出一条就不能上线。109 dedicated tests, plus a leak check on every commit that blocks release if a single record crosses clubs.

原则Principles

我们坚持的几条原则What we hold to

AI 出草稿，人做决定AI drafts, people decide

排产、报价、单据，系统给草稿，拍板的永远是人。Schedules, quotes and documents arrive as drafts; a person always makes the call.

只说有依据的话Only what the evidence supports

查不到就说查不到；每个结论都能追溯到原始记录。If nothing is found, it says so; every conclusion traces back to a record.

权限是结构，不是自觉Permissions are structural

谁能看什么，在系统底层就隔离好，而不是靠界面藏起来。Who sees what is enforced at the bottom of the system, not hidden in the interface.

能用现成工具，就不定制Off-the-shelf before custom

比如三个人管订单，先用多维表格跑几周，验证了再开发。If three people manage orders, run a shared table for a few weeks before building anything.

先定基线，再谈改善Baseline first

改之前先量清现状，效果用同一把尺子量。Measure today before changing anything, and judge results with the same yardstick.

中文优先，手机能用Chinese first, phone-ready

一线员工用得顺手，系统才会真的被用起来。Systems only get used when frontline staff find them easy.
